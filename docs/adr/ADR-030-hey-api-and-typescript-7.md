# ADR-030: Generate the frontend API client with Hey API across a TypeScript 7 boundary

- **Status:** Accepted
- **Date:** 2026-08-10
- **Deciders:** Jerry Holland
- **Amends:** [ADR-012](ADR-012-openapi-client-drift-gate.md) and
  [ADR-029](ADR-029-frontend-linting-with-oxlint.md)

## Context

ADR-012 pinned the SPA to TypeScript 5 because `openapi-typescript` did not admit the next compiler
major. That generator and `openapi-fetch` also produced only schema types plus a path-string client,
leaving the application to bind paths and response types at each call site. The SPA now needs the
native TypeScript 7 compiler without weakening the generated-client drift gate.

Hey API's generator emits named TypeScript models and a fetch SDK from the same OpenAPI document.
Version 0.99 admits TypeScript 7 in its package metadata, but its generator process still reads a
compiler API removed in TypeScript 7 and crashes when both are installed in one dependency graph.
Generated application code does compile under TypeScript 7.

## Decision

- The SPA compiles with TypeScript 7 and consumes the named models and SDK generated by
  `@hey-api/openapi-ts`.
- Code generation is an isolated package under `web/codegen`, pinned to TypeScript 5.9 until the Hey
  API CLI itself runs under TypeScript 7. The root application has no TypeScript 5 dependency.
- Generated files live under `web/src/api/generated`, remain committed, and are regenerated from the
  build-time OpenAPI document by ADR-012's CI drift gate.
- Hand-authored runtime configuration preserves same-origin credentials and the XSRF interceptor.
  Application code imports generated functions and models through `@/api`; it does not edit generated
  files or hand-write contract types.
- Dependabot and audit treat `web` and `web/codegen` as separate dependency roots. TypeScript majors
  stay muted only in the generator package while that compatibility boundary exists.

## Consequences

The production SPA and its typecheck now run on TypeScript 7, and API calls carry generated path,
query, body, response, and error shapes without string-based method dispatch. The cost is a second,
small lockfile and an explicit TypeScript 5 build-tool island. Generated function names are verbose
where endpoints lack `operationId`; that is deterministic and preferable to maintaining aliases by
hand.

## Revisit trigger

When the current Hey API generator runs successfully with the repository's TypeScript 7 version,
remove the isolated TypeScript pin and re-evaluate collapsing code generation into the root package.
Separately, add stable endpoint `operationId` values if generated names materially impede navigation.
